# makefun-office-jokes

Entry for **Make the AI Judge Laugh: Office Jokes** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
single-line joke about office life to `/output/entry.txt`:

> I finally hit inbox zero by declaring email bankruptcy and asking everyone to resend anything important. Nobody did.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
